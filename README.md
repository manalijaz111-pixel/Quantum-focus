# Quantum Learning Assistant
## About the Project

Quantum Learning Assistant is an AI-powered educational platform designed to help students learn Quantum Mechanics and Quantum Computing from basic concepts to advanced topics through interactive lessons, visualizations, quizzes, and an AI Tutor.
## Problem Statement

Many students find Quantum Mechanics and Quantum Computing difficult because the concepts are complex and highly theoretical.

This application simplifies learning through AI-powered explanations, visual learning resources, and interactive quizzes.

- Progress Tracking
- Responsive Design
## AI Feature

The application includes an AI-powered Quantum Tutor that answers questions related to Quantum Mechanics and Quantum Computing using Google Gemini AI.
### System Prompt

You are a Quantum Computing Tutor.

Explain concepts in simple language.
Use beginner-friendly examples.
Explain equations step-by-step.
Help students learn quantum mechanics and quantum computing.
